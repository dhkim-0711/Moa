## 1. [글로벌·기술] OpenAI, 자체 추론칩 ‘Jalapeño’ 실측 결과 공개…모델·칩·서빙 공동설계 본격화

- 칩 정격전력은 700W이나 시험 워크로드의 지속전력은 550W 이하였으며, prefill·decode 단계의 상이한 병목과 KV 캐시·네트워크 데이터 이동을 하나의 연결 시스템에서 함께 최적화한 구조

### 중요성

- 모델 개발사가 GPU 구매자에 머무르지 않고 실제 서비스 트래픽을 바탕으로 모델·칩·메모리·네트워크·서빙 소프트웨어를 수직 공동설계하는 단계로 진입
- 추론 경쟁의 핵심 지표가 최대 연산량에서 사용자별 토큰속도, 종단간 지연시간, 전력당 유효 처리량과 에이전트 작업 완료시간으로 이동하는 흐름
- NVIDIA GPU 중심의 범용 인프라와 모델 기업의 전용 ASIC이 공존하면서 워크로드별 가속기 선택과 멀티벤더 운영 역량의 중요성 확대

### 시사점

- 국산 NPU 평가도 TOPS·카드 전력 중심에서 벗어나 prefill·decode 분리성능, KV 캐시 배치, 종단간 지연시간, 토큰/kW와 에이전트 작업 완료시간까지 측정할 필요
- 국내 모델·NPU·서빙 기업이 공동으로 실제 요청 분포를 반영한 레퍼런스 시스템을 설계하고, 동일 모델·정확도·컨텍스트 길이 조건에서 제3자 비교검증을 수행할 필요
- 특정 칩에 최적화된 모델이 다른 인프라로 이전되지 못하는 위험에 대비해 표준 API, 모델 패키징, 커널 이식성과 멀티가속기 라우팅을 공공사업의 필수 성과물로 확보할 필요

- 국내 이기종 컴퓨팅 사업도 GPU·NPU를 단순 병렬 배치하는 수준을 넘어 prefill·decode·임베딩·재랭킹 등 추론 단계를 분리해 최적 자원에 배치하는 구조 검증 필요
- 오케스트레이션 평가에 모델 단계별 라우팅, KV 캐시 이동비용, 가속기 간 대기시간, p95 지연시간과 장애 시 대체경로를 포함할 필요
