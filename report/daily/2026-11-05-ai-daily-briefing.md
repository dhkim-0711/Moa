## 3. [해외·AI CPU] Arm, AGI CPU 매출 20억달러 전망…Google TPU 시스템에도 Axion 투입

![Arm 기반 데이터센터 CPU](https://cloudfront-ap-northeast-1.images.arcpublishing.com/chosun/GI3GGNJYGM3DAYJZGM3DOOBSGI.jpg)

### 주요 내용

- Arm은 2027·2028 회계연도 AGI CPU 매출을 약 20억달러로 예상하고 필요한 공급능력을 확보했다고 밝혔으며, 상용 납품은 2027 회계연도 4분기부터 시작할 계획
- Google이 TPU 시스템에 Arm 기반 Axion CPU를 사용하고 있으며, Arm은 상위 하이퍼스케일러 서버 배치 비중이 2025년 50%를 넘어 2026년 말 60%를 상회할 것으로 전망
- 2분기 매출은 14억4,000만달러로 전년 대비 27% 증가했고 라이선스 7억7,300만달러·로열티 6억7,000만달러, 다음 분기 매출 전망은 15억4,000만달러

### 중요성

- Arm이 설계 IP 제공을 넘어 완성형 데이터센터 CPU 매출을 구체화하면서 x86·커스텀 실리콘·GPU가 결합된 AI 서버 수익구조에 직접 진입하는 변화
- TPU와 Axion 결합은 AI 클러스터 경쟁이 가속기 단품보다 호스트 CPU·메모리·인터커넥트의 시스템 최적화로 이동했음을 보여주는 사례
- 20억달러는 회사 전망이며 실제 매출은 고객 도입·수율·공급일정에 좌우되므로 수주잔고와 양산 인도 실적을 구분할 필요

### 시사점

- 국내 NPU·서버 사업은 x86 고정형 구성을 벗어나 Arm 호스트 CPU와의 컴파일러·메모리·가상화 호환성까지 포함한 레퍼런스 설계 확보 필요
- 공공 AI 인프라 조달은 GPU 처리량과 함께 CPU 병목, 데이터 전처리·네트워크 오프로딩, 노드당 전력과 라이선스 비용을 통합 평가할 필요
- 국내 팹리스·메모리기업은 Arm AGI CPU의 실제 인터페이스·HBM·DDR 수요를 조기 검증해 커스텀 실리콘 공급망 진입기회를 확보할 필요
