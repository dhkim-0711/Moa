- 한국전력·리벨리온·한국정보통신기술협회(TTA)가 변전소 AI 영상분석을 위한 국산 NPU 실증 협약을 체결하고, 변전소별 분산 인프라를 NPU 기반 통합 관제 시스템으로 전환해 시범 운영할 계획

- 지난해 마련된 K-Perf가 수요기관의 실제 도입 판단 기준으로 사용되는 첫 사례이며, 지난 6월 리벨리온·퓨리오사AI 대상 생성형 AI 시험에서 전력 영상분석으로 검증범위를 확장

- 국산 NPU 평가가 TTFT·TPOT·TPS 중심 실험실 벤치마크에서 장기 관제·영상처리·장애복구가 필요한 공공 전력현장으로 이동하는 전환점

- 비용절감과 안정성은 아직 검증 계획 단계이며, 기업·정부의 기대효과를 확정 성과로 간주하기보다 GPU 대비 전력·지연·가동률·총소유비용의 실제 측정값 확인 필요

### 시사점

- 공공 NPU 사업은 칩의 최고 연산량보다 현장 모델 정확도, 와트당 유효처리량, 장애복구시간과 24시간 운영비를 K-Perf 필수 공시항목으로 관리할 필요
- 한전 실증 데이터를 익명화해 다른 관제·교통·재난기관이 재시험할 수 있도록 하고, 국산 NPU 간 동일 워크로드 결과와 교체·이식 비용을 공개할 필요
- 실증 통과를 자동 구매로 연결하지 말고 보안패치, 모델 업데이트, 부품수급과 공급사 중단 시 워크로드 이전 조건까지 조달계약에 포함할 필요

- Amazon이 미국 5개 주 12곳 이상의 데이터센터에 설치 중인 수천 개 Nvidia Grace Blackwell 칩 약 80억달러어치를 특수목적기구(SPV)로 이전하는 방안을 투자자와 협의 중이라고 Financial Times가 관계자를 인용해 보도
- SPV는 외부 투자자 대상 부채를 발행하고 Amazon은 칩을 다시 임차하는 구조이며, Amazon이 기구 지분을 최대 10% 제공하는 방안도 검토
- 대상 칩은 Amazon이 구매했거나 임차한 물량으로 전해졌으나, Amazon·Nvidia는 Reuters의 확인 요청에 즉시 답하지 않아 거래조건·종결 여부는 미확정

### 중요성

- AI 가속기를 운영사 재무제표에 장기 보유하는 방식에서 칩 현금흐름을 분리해 외부자본으로 조달하는 유동화·세일앤리스백형 금융으로 확장되는 사례
- 서버 건물뿐 아니라 GPU 자체가 담보·임대자산이 되면서 장비세대 교체, 중고가격, 고객 집중도와 임대료 지급능력이 데이터센터 금융의 핵심 위험으로 부상
- 80억달러는 확정 매각대금이 아니라 협의 중인 자산규모이며, 최신 칩의 높은 초기 가치가 감가·기술전환 이후에도 유지된다는 보장은 부재

### 시사점

- 국내 AIDC·정책금융은 GPU·NPU 담보가치를 정가가 아닌 세대별 중고가격, 재배치 가능성, 소프트웨어 호환성과 잔존수요로 할인 평가할 필요
- SPV 부채와 장기 임차약정이 운영사의 실질 부채·고객위험을 가리지 않도록 최소사용료, 조기해지, 칩 고장·교체 책임과 최종 손실부담을 연결 공시할 필요
- 국산 NPU 금융모델도 공급사 보증에만 의존하지 않고 여러 모델·클라우드에서 재사용 가능한 표준 소프트웨어와 제3자 성능검증을 담보가치의 전제조건으로 설정할 필요

## 3. [미국·AI 에이전트 보안] Apple, macOS 전체 디스크 접근에 추가 명시적 동의 도입 예고

![Mac에서 실행되는 AI 에이전트의 데이터 접근 통제](https://images.unsplash.com/photo-1517336714731-489689fd1ca8?auto=format&fit=crop&w=1600&q=80)

### 주요 내용

- Apple이 AI 에이전트가 Mac의 파일·메일·메시지·브라우징 기록 전체에 접근할 수 있는 ‘Full Disk Access’를 요청할 때 사용자가 위험을 분명히 인지하도록 추가 통제를 도입할 계획
- Apple은 일부 개발자가 백업 앱용 예외권한을 사용자 이해 없이 광범위하게 사용해 위험을 만들고 있다고 지적하고, 향후 ‘매우 명시적인 사용자 행동’으로만 권한을 부여하도록 하겠다고 발표
- 조치는 Meta Muse가 비공개 메시지를 읽었다는 사용자 주장 뒤 공개됐으며, Meta는 Full Disk Access와 Messages 커넥터를 모두 사용자가 켜야 하고 언제든 철회 가능하다는 입장

### 중요성

- 에이전트 보안의 초점이 모델 응답필터에서 운영체제 권한·도구 호출·앱 간 데이터 경계로 이동하며, 범용 에이전트가 기존 데스크톱 권한모델의 허점을 확대하는 문제를 공식화
- 한 번의 포괄 동의로 모든 파일을 읽는 구조보다 목적별·작업별 권한과 재승인이 필요하다는 플랫폼 차원의 신호로, 에이전트 개발사의 기능설계와 사용자 경험에 직접 영향
- Apple은 통제의 구체 일정·API·호환성 사양을 아직 공개하지 않았고 Muse 접근 여부도 당사자 주장이 엇갈려, 사고 사실과 예방조치 계획을 구분해 볼 필요

### 시사점

- 국내 공공·금융 PC용 에이전트는 전체 디스크 권한을 원칙적으로 금지하고 파일·앱·기간·작업별 최소권한, 고위험 읽기·전송 전 재승인과 즉시 철회 기능을 요구할 필요
- 조달평가에 모델명보다 실제 OS 권한, 하위 에이전트·커넥터 호출로그, 외부전송 목적지와 민감정보 마스킹·사후 포렌식 가능성을 포함할 필요
- 국산 에이전트·보안제품은 macOS·Windows의 권한변경에 종속되지 않도록 표준 권한 브로커와 정책엔진을 설계하고, 기능저하·호환성 비용을 사전에 시험할 필요

## 4. [유럽·슈퍼컴퓨팅 공급망] Bull “프로세서보다 메모리가 마지막 약점”…유럽 공급자 부재 확인

### 주요 내용

- Bull CEO가 유럽에서 조달 가능한 슈퍼컴퓨터 부품 비중이 5년 전 20~30%에서 현재 약 70%로 늘었지만, 메모리는 유럽 공급자가 없는 마지막 주요 부품이라고 설명
- SiPearl·Vsora·Openchip 등 유럽 프로세서 진전을 언급하면서 프로세서는 슈퍼컴퓨터 가치의 10~20%에 그친다고 밝혔고, 메모리 가격 급등을 업계 최대 우려 중 하나로 지목
- 전일 Bull 생산확대 보도에서 새로 추가된 사실은 메모리 공급자 부재, 프로세서 가치비중 10~20%, Samsung·SK hynix·Micron의 세계 메모리 생산 90% 이상 집중이라는 공급망 수치

### 중요성

- 유럽의 컴퓨팅 주권이 CPU·보드·냉각의 현지화만으로 완성되지 않으며, HBM·DRAM 조달가격과 공급우선순위가 슈퍼컴퓨터 납기·원가를 좌우하는 구조 확인

- 90% 이상을 차지하는 3사 가운데 한국 기업 2곳이 포함돼 한국에는 수출기회인 동시에 특정 고객·지역의 정책압력과 공급집중 위험이 확대

### 시사점

- 한국은 HBM·DRAM 수출을 물량계약에 그치지 않고 유럽 패키징·모듈·검증거점과 결합해 시스템 설계단계부터 장기 수요를 확보할 필요
- 공공 슈퍼컴퓨터·AIDC 사업은 GPU·CPU뿐 아니라 메모리 용량·대역폭·가격변동, 공급중단과 대체 모듈 인증시간을 별도 위험지표로 관리할 필요
- 국산 NPU 경쟁력 평가도 연산칩 단품보다 HBM·CXL·스토리지와의 통합성, 모델별 메모리 병목과 토큰당 총시스템 비용을 함께 측정할 필요
